# 屏幕扫描助手 — 使用说明

> 一款常驻后台的屏幕识别小工具：按快捷键框选屏幕区域（或上传图片），自动识别其中的**文字与图片**，一键复制。
> 全部识别在**本地离线**完成，内容不上传网络，断网可用。

## 一、安装

**无需安装**：双击 `屏幕扫描助手.exe` 即可使用（首次启动约 1~3 秒加载识别引擎）。

> 若被杀毒软件拦截，选择「信任/允许」即可；如遇误报可改用文件夹版。

## 二、基本操作

| 操作 | 方法 |
|------|------|
| **框选识别（最常用）** | 按 `Alt+S` → 屏幕变暗 → 按住左键拖动框选区域 → 松开自动识别 |
| **全屏扫描** | 按 `Alt+Shift+S` 或主窗口「全屏扫描」按钮 |
| **上传图片识别** | 主窗口「上传图片识别」→ 选择本地图片 |
| **取消框选** | 按 `Esc` 或点鼠标右键 |
| **显示/隐藏主窗口** | 单击托盘图标 |
| **退出软件** | 托盘右键 → 退出 |

## 三、结果窗口操作

- 右侧文字列表：**单击选中、双击该行**即复制该行文字；`Ctrl+C` 复制全部文字
- 「复制全部文字」「导出 .txt」：整段文字
- 「复制图片」「保存图片」：区域截图/上传图片本身
- 「提取图中图片」：开启后在左侧图片上**再框选一块**，松手即把该小块图片复制到剪贴板（用于从截图里抠出单张图片素材）
- 「置顶」：结果窗始终显示在最上层（默认开启，可在设置中修改）

## 四、设置

主窗口右上角「⚙ 设置」：

- **快捷键**：框选识别、全屏扫描两个热键均可改（支持 Alt/Ctrl/Shift/Win 组合与 F1-F12 等；写法示例 `ctrl+alt+s`、`f9`）
- **结果窗自动置顶**：开关
- **开机自动启动**：开关（开启后开机后台待命）

## 五、数据与隐私

- 设置与历史记录保存在本机：`%LOCALAPPDATA%\ScreenScan\`
- 不作任何网络上传；删除该文件夹即可清除全部数据

## 六、速度与性能（实测）

- 识别引擎：RapidOCR **PP-OCRv6**（本地离线，关闭方向分类优化速度）
- 本机实测（18 核 CPU / 200% 缩放）：框选区域约 **1 秒**内出结果；全屏扫描（2560×1600）约 **2.6 秒**
- 启动后后台预加载识别引擎，首次识别无需额外等待

## 七、常见问题

| 现象 | 处理 |
|------|------|
| 快捷键无反应 | 可能与其他软件冲突 → 设置里换一个热键 |
| 识别不准确 | 框选范围大一些；避免手写/艺术字/极小的字 |
| 截不到某些窗口 | UAC 管理员弹窗、部分独占全屏游戏无法截取（系统限制） |
| 开机自启设置后未生效 | 检查是否被安全软件拦截；重新开关一次 |
| 出现异常或卡住 | 查看日志 `%LOCALAPPDATA%\ScreenScan\log\app.log`，反馈问题时一并提供 |
| 如何升级 | 直接替换 exe 文件即可（设置与历史自动保留） |
