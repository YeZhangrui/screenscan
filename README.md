# 屏幕扫描助手 — 使用说明

> 一款常驻后台的屏幕识别小工具：按快捷键框选屏幕区域（或上传图片），自动识别其中的**文字与图片**，一键复制。
> 全部识别在**本地离线**完成，内容不上传网络，断网可用。

## 一、安装

**无需安装**：双击 `屏幕扫描助手.exe` 即可使用（首次启动约 1~3 秒加载识别引擎）。

> 若被杀毒软件拦截，选择「信任/允许」即可；如遇误报可改用文件夹版。

## 二、基本操作

| 操作 | 方法 |
|------|------|
| **框选识别（最常用）** | 按 `Alt+S` → 屏幕变暗 → 按住左键拖动框选区域 → 松开后**截图立即留在屏幕上**（显示「正在识别…」），识别完成原地变为可交互面板 |
| **就地复制（新）** | 识别完成后结果**直接浮在屏幕原位置**：点选/拖拽框选文字 → 点操作条「复制选中」，全程不用切回软件窗口 |
| **全屏扫描** | 按 `Alt+Shift+S` 或主窗口「全屏扫描」按钮（同样弹出屏幕浮层，可就地选文字） |
| **上传图片识别** | 主窗口「上传图片识别」→ 选择本地图片 → 打开结果窗口 |
| **取消框选** | 按 `Esc` 或点鼠标右键 |
| **显示/隐藏主窗口** | 单击托盘图标 |
| **退出软件** | 托盘右键 → 退出 |

## 三、屏幕浮层（识别后直接选字复制）

识别完成后，结果浮层出现在**截图的原位置**（文字上带蓝色高亮框），**操作条位于框选区域外**（下方优先，下方空间不足则显示在上方），小区域也不会被遮挡：

| 操作 | 说明 |
|------|------|
| **单击某段文字** | 选中该段；**继续点其他段可累加多选**（无需按 Ctrl）；再点一次取消 |
| `Shift` + 单击 | 从上次点击处连选到该段 |
| `Ctrl` + 单击 | 追加/取消选中（兼容习惯） |
| 拖拽框选 | 一次选中框到的所有文字段 |
| 点面板空白处 | 清空选中 |
| `Ctrl+A` / `回车` | 全选 / 复制已选文字 |
| 操作条「复制选中」 | 把选中的文字按原顺序复制到剪贴板 |
| 操作条「复制全部 / 复制图片」 | 复制全部文字 / 复制该区域图片 |
| 操作条「详细结果」 | 打开完整结果窗口（多选、导出 txt、抠图等） |
| `Esc` 或「关闭」 | 关闭浮层 |
| 拖拽面板边缘 / 右下角 | 调整面板大小（等比缩放，文字与识别框始终对齐） |

## 四、结果窗口操作

- 右侧文字列表：**勾选或 `Ctrl`/`Shift` 多选**多段文字 → 点「复制选中」批量复制；「全选 / 取消全选」一键切换；双击单行复制该行
- 「复制全部文字」「导出 .txt」：导出时若有勾选则只导出选中的文字
- 「复制图片」「保存图片」：区域截图/上传图片本身
- 「提取图中图片」：开启后在左侧图片上**再框选一块**，松手即把该小块图片复制到剪贴板（用于从截图里抠出单张图片素材）
- 「置顶」：结果窗始终显示在最上层（默认开启，可在设置中修改）

## 五、设置

主窗口右上角「⚙ 设置」：

- **快捷键**：框选识别、全屏扫描两个热键均可改（支持 Alt/Ctrl/Shift/Win 组合与 F1-F12 等；写法示例 `ctrl+alt+s`、`f9`）
- **结果窗自动置顶**：开关
- **开机自动启动**：开关（开启后开机后台待命）

## 六、数据与隐私

- 设置与历史记录保存在本机：`%LOCALAPPDATA%\ScreenScan\`
- 不作任何网络上传；删除该文件夹即可清除全部数据

## 七、速度与性能（实测）

- 识别引擎：RapidOCR **PP-OCRv6**（本地离线，关闭方向分类优化速度）
- 本机实测（18 核 CPU / 200% 缩放）：框选区域约 **1 秒**内出结果；全屏扫描（2560×1600）约 **2.6 秒**
- 启动后后台预加载识别引擎，首次识别无需额外等待

## 八、常见问题

| 现象 | 处理 |
|------|------|
| 快捷键无反应 | 可能与其他软件冲突 → 设置里换一个热键 |
| 识别不准确 | 框选范围大一些；避免手写/艺术字/极小的字 |
| 截不到某些窗口 | UAC 管理员弹窗、部分独占全屏游戏无法截取（系统限制） |
| 开机自启设置后未生效 | 检查是否被安全软件拦截；重新开关一次 |
| 出现异常或卡住 | 查看日志 `%LOCALAPPDATA%\ScreenScan\log\app.log`，反馈问题时一并提供 |
| 如何升级 | 直接替换 exe 文件即可（设置与历史自动保留） |
